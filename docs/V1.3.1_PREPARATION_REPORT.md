## Display acceptance and limits

Automated bounds checks and 24 rendered page images cover **1460x900, 1100x700 and 1024x600**. Every result grid retains usable geometry; Traceroute inputs fit their frames. Evidence: `artifacts/ui-131/` and Maintenance test output. These images are `DrawToBitmap` captures hosted by the test executable; its generic icon is not the packaged icon.

Native dropdown/modal/pointer visual acceptance remains **NOT VERIFIED**. The native capture tool returned an unrelated foreground application's image while its accessibility tree identified the isolated NetStuck window. Those images were not retained as release evidence. Right edges of some input controls appear incomplete in `DrawToBitmap`; bounds checks pass, but native visual confirmation is still required. Physical 125/150/200% scaling, moves between monitors, High Contrast and screen reader acceptance also remain pending. System DPI awareness is implemented; native per-monitor DPI rerendering is not.

The release must not be described as validated on every resolution or as fully accepted stable until these relevant manual checks are recorded.
