# v1.3.3 — Light and Dark themes

The owner selected publication as v1.3.3 so existing v1.3.2 installations can discover an update. The earlier instruction to leave testing to the owner is retained: tests, runtime smoke, UI screenshots, updater execution and CI are **NOT RUN**. Successful compilation and package hashes are delivery checks, not runtime acceptance.

The application header provides Theme: Light / Dark. The choice is saved as an optional `Theme` string in the existing state schema 6, with Light as the fallback for older or unknown state. Theme changes recolor the current controls and invalidate drawing without rebuilding forms, rebinding result tables or restarting monitoring.

Theme coverage includes readable foreground/surface pairs, status colors, column headers, alternating rows, selected cells, text/numeric inputs, dropdown items, main/session tabs, buttons including disabled labels, status strip, column-selection dialogs and saved-list/hop-description dialogs. The Collector terminal retains its own dark palette. Inherited colors stay inherited so status panels continue propagating their background when their state changes. Normal, hover and pressed button colors retain their semantic roles.

Windows-native file dialogs, message boxes, scrollbars and system chrome retain Windows rendering. Native dropdown-open appearance, repeated theme switching during live work, physical DPI/multi-monitor behavior and restart persistence have not been exercised for this release; they await owner acceptance. Historical v1.3.1 test totals do not validate v1.3.3.

The source snapshot is published on `codex/release-v1.3.3`, tagged `v1.3.3`, and distributed as a normal Latest GitHub Release for the existing updater. The commit includes `[skip ci]` for the explicit no-test workflow. Previously published v1.3.2 artifacts are preserved; main is not merged during this release task.

Build recipe: `scripts/Build-NetStuck.ps1 -OutputDirectory artifacts/build-133`. Packaging follows the existing nine-file portable contract, with a new TEST-REPORT.txt explicitly marking tests not run, internal SHA256 checksums and a companion ZIP checksum. The package report records the exact source commit, EXE hash and source-input fingerprint. No operator state or capture files are included.

User procedure: in 1.3.2 select Updates → Check for updates → Update now. After 1.3.3 starts, choose Theme → Dark in the header; switch back to Light using the same selector. Theme settings remain local.
